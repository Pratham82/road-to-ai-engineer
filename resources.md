## Books

### Best books for 2026 (AI Engineer focus)

| Book | Author | Best for |
|---|---|---|
| **AI Engineering** | Chip Huyen (2025) | The "bible" for the AI Engineer role — building reliable AI systems in production. |
| **Build a Large Language Model (From Scratch)** | Sebastian Raschka | Understanding how an LLM works at the code level. |
| **The LLM Engineering Handbook** | Paul Iusztin & Maxime Labonne | Practical how-to for RAG, fine-tuning, and evaluation. |
| **Designing Machine Learning Systems** | Chip Huyen | How data pipelines and model lifecycles differ from standard software. |
| **Hands-On Large Language Models** | Jay Alammar | Mental models of modern AI (attention, transformers). |

### The "Core Six"

| Area | Resource |
|---|---|
| Mathematics | *Mathematics for Machine Learning* (Deisenroth, Faisal, Ong) |
| Machine Learning | *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow* (Géron) |
| Deep Learning | *Dive into Deep Learning* (d2l.ai) |
| LLMs | *Build a Large Language Model (From Scratch)* (Raschka) |
| MLOps | *Designing Machine Learning Systems* (Huyen) |
| Transformers | *Attention Is All You Need* (paper) |

### By topic

- **Math:** Mathematics for Machine Learning (Deisenroth et al.) · Linear Algebra and Its Applications (Strang) · Introduction to Linear Algebra (Strang) · Think Stats · Practical Statistics for Data Science.
- **Classical ML:** Hands-On Machine Learning (Géron) · An Introduction to Statistical Learning (ISL) · The Hundred-Page Machine Learning Book · Pattern Recognition and Machine Learning (advanced).
- **Deep Learning:** Deep Learning (Goodfellow, Bengio, Courville) · Dive into Deep Learning (d2l.ai) · Deep Learning for Vision Systems.
- **Transformers / LLMs / NLP:** Natural Language Processing with Transformers (Tunstall et al.) · Hands-On Large Language Models (Alammar) · Build a Large Language Model From Scratch (Raschka) · Speech and Language Processing (Jurafsky & Martin).
- **MLOps / AI Engineering:** AI Engineering (Huyen) · Designing Machine Learning Systems (Huyen) · The LLM Engineering Handbook · Practical MLOps.
- **Infrastructure (optional):** CUDA by Example.

## Math resources

Learning platforms for the [Maths for ML roadmap](roadmaps/maths-for-ml.md):

- [Khan Academy](https://www.khanacademy.org/) — free, beginner-friendly; Statistics & Probability, Linear Algebra, Calculus.
- [Paul's Online Math Notes](https://tutorial.math.lamar.edu/) — best free notes for Algebra, Calculus I–III, Differential Equations, with solved problems.
- [MIT OpenCourseWare](https://ocw.mit.edu/) — 18.01 Single Variable Calculus, 18.06 Linear Algebra; rigorous.
- [3Blue1Brown](https://www.youtube.com/@3blue1brown) — visual explanations (also in [`playlists.md`](playlists.md)).
- [OpenStax (Rice)](https://openstax.org/) — free peer-reviewed college textbooks (Calculus, Statistics, Linear Algebra).
- [Brilliant.org](https://brilliant.org/) — interactive, puzzle-based (partly paid).
- [Mathigon](https://mathigon.org/) — "world's most interactive math textbook," free.
- [Expii](https://www.expii.com/) — community-driven, multiple explanations per topic.
- [Wolfram MathWorld](https://mathworld.wolfram.com/) — comprehensive math encyclopedia.
