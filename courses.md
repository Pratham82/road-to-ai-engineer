## Foundational / structured courses

### Math
- [Mathematics for Machine Learning Specialization](https://www.coursera.org/specializations/mathematics-machine-learning) — Imperial College London (Coursera). Linear algebra + multivariable calculus, ML-framed.
- [Mathematics for Machine Learning - Linear Algebra](https://www.youtube.com/playlist?list=PLiiljHvN6z1_o1ztXTKWPrShrMrBLo5P3) (YouTube).
- Khan Academy — [Statistics & Probability](https://www.khanacademy.org/math/statistics-probability), Linear Algebra, Calculus (free; fills the stats/probability gap).

### Machine Learning
- [Machine Learning Specialization](https://www.coursera.org/specializations/machine-learning-introduction) — Andrew Ng / DeepLearning.AI (Coursera). The industry-standard starting point; 2022 version uses Python/NumPy.
- StatQuest with Josh Starmer — see [`playlists.md`](playlists.md) (used alongside Ng's course).

### Deep Learning
- [Practical Deep Learning for Coders](https://course.fast.ai/) — fast.ai (free). Top-down, code-first.
- [Deep Learning Specialization](https://www.coursera.org/specializations/deep-learning) — Andrew Ng / DeepLearning.AI.
- [PyTorch for Deep Learning](https://www.coursera.org/professional-certificates/pytorch-for-deep-learning) (DeepLearning.AI / Coursera) — tensors → deployment/MLOps.
- [PyTorch: Fundamentals](https://www.coursera.org/learn/pytorch-fundamentals) (Microsoft / DeepLearning.AI) — shorter, hands-on intro.

### Applied AI / LLMs
- [Generative AI for Software Development](https://www.deeplearning.ai/courses/generative-ai-for-software-development/) (DeepLearning.AI) — LLMs for code, testing, system design.
- **DeepLearning.AI short courses** — "LangChain for LLM Application Development," "Building and Evaluating Advanced RAG," "Finetuning Large Language Models," "Building Systems with the ChatGPT API." Short, built with the tool vendors, stay current.
- [Hugging Face LLM / NLP Course](https://huggingface.co/learn/llm-course) (free) — tokenization, fine-tuning, the Transformers library. Very hands-on.
- **Full Stack LLM Bootcamp** / Full Stack Deep Learning (free lectures) — deploy, monitor, evaluate LLM systems in production.
- [Generative AI Full Course 2026](https://www.youtube.com/watch?v=mnkiYN6qikw) (Simplilearn, YouTube) — free ~16-hr resource covering LangGraph + Agentic AI.

### Practical / data
- [Kaggle micro-courses](https://www.kaggle.com/learn) — "Pandas," "Intro to Machine Learning" (free, few hours each).
- [Free Nvidia Courses](https://www.nvidia.com/en-us/training/find-training/?Free+Courses=Free).
