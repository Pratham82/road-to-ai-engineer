# Phase 0: Python for AI

Here's the full breakdown of Phase 0 — a quick refresh so Python and the data stack are never the bottleneck in the phases that follow.

**Duration: 1-2 weeks** (skim/refresh only — assumes you already have working Python basics)

## What you're building here

Python fluency specifically for AI/data workflows, not general-purpose scripting. This phase is a refresh, not a from-scratch learn — skip anything that already feels familiar.

## Topics

- Type hints, iterators, generators, decorators, context managers, dataclasses
- Virtual environments and packaging (Poetry or Rye — feels like a stricter TypeScript)
- AsyncIO basics, APIs, JSON/tool-calling patterns (needed later for agent work)
- **The Big Three libraries:** NumPy (vectorized math), Pandas (dataframes), Matplotlib (plotting)
- Jupyter Notebooks as your working environment

## Courses & books

- **Course:** Python for Everybody (skim advanced sections only)
- **Books (reference):** _Python Tricks_, _Effective Python_
- **Libraries to get comfortable with:** NumPy, Pandas, Matplotlib, SciPy, Jupyter

More picks live in the root [courses](../../courses.md) and [resources](../../resources.md) files.

## Checkpoint before moving to Phase 1

You should be able to:

- Work comfortably in a Jupyter notebook without looking up basic syntax
- Explain what a NumPy vectorized operation is replacing (a loop) and why it's faster
- Have virtual env + package management set up and second-nature
